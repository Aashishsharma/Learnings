# Lightsail
- offers simple, low-cost virtual servers with bundled compute, storage, and networking for small apps and websites.
- It’s designed for fast, easy deployments—great for beginners (who are not AWS cloud experts) or quick prototypes without managing complex AWS services.

#### AWS Lightsail = "I want a SIMPLE SERVER"
- AWS gives you a VM and a few simple cloud resources.
- You manage the OS and application yourself.
- **Example:** WordPress site, small business website.

#### AWS Elastic Beanstalk = "I want to DEPLOY AN APPLICATION"
- You provide application code, and AWS manages the underlying infrastructure.
- You still have access to and control over the EC2 instances if needed.
- **Example:** Deploy a Java, Node.js, Python, or .NET application.

#### AWS Amplify = "I want to BUILD A WEB/MOBILE APPLICATION FAST"
- AWS provides hosting plus integrated services like authentication, APIs, storage, and CI/CD.
- Geared toward full-stack web/mobile developers rather than infrastructure management.
- **Example:** React app with Cognito authentication and AppSync/API backend.
